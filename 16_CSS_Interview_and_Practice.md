# 16 — CSS Interview and Practice

## Beginner questions

### 1. What is CSS?

CSS stands for Cascading Style Sheets. It controls the presentation of HTML documents.

### 2. What are the three ways to apply CSS?

Inline, internal and external CSS.

### 3. What is the difference between class and ID selectors?

A class is reusable across multiple elements. An ID should identify one unique element in a document.

### 4. What is the CSS box model?

It consists of content, padding, border and margin.

### 5. What is the difference between margin and padding?

Margin is outside the border; padding is between content and border.

## Intermediate questions

### 6. What is Flexbox?

A one-dimensional layout system for arranging items along a row or column.

### 7. What is CSS Grid?

A two-dimensional layout system for rows and columns.

### 8. What is specificity?

A set of rules used by the CSS cascade to resolve competing selectors.

### 9. What is a media query?

A conditional CSS rule used to apply styles based on media features such as viewport width.

### 10. What is `z-index`?

It controls the stacking order of positioned elements and items in relevant layout contexts, subject to stacking contexts.

**Q3. Which property adds space inside an element's border?**
