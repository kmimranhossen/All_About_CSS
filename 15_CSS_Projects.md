# 15 — CSS Projects

Build these projects in order. Use HTML for structure and CSS for styling.

## Project 1: Profile Card

**Requirements**
- Profile image or avatar
- Name, short bio and social links
- Rounded card, shadow and hover state
- Responsive width

## Project 2: Responsive Navigation Bar

**Requirements**
- Brand/logo
- Navigation links
- Flexbox layout
- Adapt layout for narrow screens
- Visible keyboard focus

## Project 3: Product Card Grid

**Requirements**
- At least six product cards
- CSS Grid layout
- Image, title, price and button
- Responsive columns
- Consistent spacing

## Project 4: Login Form

**Requirements**
- Email and password fields
- Labels associated with inputs
- Focus and invalid states
- Clear button styles
- Accessible contrast

## Project 5: Personal Portfolio

**Sections**
- Hero
- About
- Skills
- Projects
- Contact

**Requirements**
- Mobile-first responsive layout
- Flexbox and Grid
- Reusable CSS variables
- Consistent typography
- Subtle transitions
- Reduced-motion support

## Project checklist

- [ ] Semantic HTML
- [ ] Responsive on mobile, tablet and desktop
- [ ] Keyboard accessible
- [ ] Images have meaningful alt text
- [ ] No horizontal overflow
- [ ] CSS is organized and readable
- [ ] Tested in a browser
