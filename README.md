## How to use

1. Learn the topics in order.
2. Type the examples yourself instead of only copying them.
3. Change values and observe the result in a browser.
4. Complete the exercises and projects.
5. Keep your HTML, CSS and JavaScript practice in separate folders when building full websites.

## Basic setup

Create an `index.html` file and a `style.css` file, then link the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

## Goal

Build a strong CSS foundation and gradually create responsive, accessible and polished web interfaces.
